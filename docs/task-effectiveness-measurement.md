# Task and Token Effectiveness Measurement

Token reduction is a hypothesis, not an implementation result. Use matched
completed tasks from a baseline and shadow cohort, version the task taxonomy,
and record governance overhead separately from total task input/output tokens.

Required outcomes are turns, rework prompts, accepted-output rate, elapsed time,
and an independently scored quality result. A token claim may be published only
after the quality non-inferiority margin and method are approved and pass.

The machine-readable empty template is
`evidence/task-effectiveness-template.json`. Its default
`publicationAllowed: false` prevents an unmeasured “50% reduction” statement
from being represented as evidence.
